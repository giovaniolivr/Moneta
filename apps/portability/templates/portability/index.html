Backup do banco

Cópia consistente do arquivo do banco (SQLite), feita no computador onde o Moneta roda. Mantém as 10 cópias mais recentes na pasta backups/.

uv run python manage.py backup

Para automatizar no Windows, crie uma tarefa diária no Agendador de Tarefas executando esse comando na pasta do projeto. Opções: --destino PASTA e --manter N.

Para restaurar, com o servidor parado: uv run python manage.py restaurar_backup backups/<arquivo> --confirmar. O banco atual é guardado antes.
